QR Code Per Cabang

Setiap QR mengarah ke halaman pencatatan cabang tersebut. Cetak lalu tempel di cabang. Nama berkas PNG mengikuti kode cabang (misalnya QR_RM_A_C1.png).

Untuk membuat semua PNG sekaligus dari terminal: npm run qr (hasil tersimpan di folder qr-codes/).
